# Changelog — Akvilon InHome

Все заметные изменения интеграции Akvilon InHome.

## [video-viewer] — 2026-10-09

### Добавлено
- **Автоматическая панель «Аквилон»** (`dashboard.py`): Lovelace-дашборд с видами
  Обзор / Камеры / Калитки / Домофоны / Счётчики / Киоск. Создаётся при установке
  интеграции, удаляется при удалении.
- **Запись видео** в веб-панели (`viewer.py` → `Recorder`): запись камеры в MP4
  через ffmpeg (`/record/start|stop|status`, `/recordings`, `/file/<name>`).
- **Современный UI** панели камер: тёмная тема, индикаторы LIVE/FPS/часы,
  кнопка записи с таймером REC, ленивая загрузка снимков (IntersectionObserver).
- **`PROTOCOL.md`**: полное описание UDP-протокола (авторизация, формат пакета,
  получение списка камер, многосессийность, видео, запись).

### Исправлено
- `protocol.py`: в `openCamera`/`request_camera_settings` добавлен обязательный
  `state_time` — без него сервер не присылает `cameraSettings`.
- `coordinator.py`: `pass_hex=self.token` в `_new_client()` — неверная подпись
  PASS ломала получение камер (сервер отвечал `0x82`).
- `viewer.py`: декодирование `unquote` в `/snap/` и `/mjpeg/` (браузер кодирует
  `:` как `%3A`); `force=True` для MJРEG (иначе кэш «замораживал» картинку).
- `PROTOCOL.md`: санитизация — реальные секреты владельца заменены плейсхолдерами.

## [video] — 2026-10-08
- Реальный видеопоток камер запущен: `openCamera` → `cameraSettings` →
  подписочный пакет `b"\x00\x00"+videoToken` → RTP/H.264 → JPEG через ffmpeg.
- Веб-панель просмотра всех камер (viewer.py): сетка, снимки, MJPEG.
