# Журнал изменений — Akvilon InHome

Все суммы и статусы указаны в рублях РФ. Версии следуют SemVer.

## v1.7.0-beta1 (2026-10-08)

### Новые функции

- **Живое видео камер** — кадр камеры по запросу через UDP/RTP: `openCamera`
  → `cameraSettings` (videoPort/videoToken/SPS-PPS) → подписочный пакет
  `b"\x00\x00"+videoToken` → приём RTP/H.264 → декод в JPEG (ffmpeg).
  Реализовано `rtp_stream.py` + `hub.camera_frame()`. После захвата камера
  закрывается (`closeCamera`), чтобы не копить лимит активных сессий на сервере.
- **Веб-панель камер** (`viewer`) — локальный HTTP-сервер (порт 8090 по
  умолчанию) со сеткой всех камер, снимками по запросу и живым MJPEG для
  выбранной. Управляется сервисами `start_viewer` / `stop_viewer`.
- **Кадр камеры в HA** — `camera.async_camera_image()` теперь возвращает реальный
  JPEG (запуск RTP в executor, не блокирует event loop).

### Прочее

- Исправлен вызов конструктора камер: в `async_setup_entry` передаётся `hass`.
- Добавлены юнит-тесты (`tests/`) для protocol, coordinator, rtp_stream, viewer:
  `./scripts/setup_test_env.sh` + `./scripts/run_tests.sh` (53 теста).

## v1.6.0 (2026-10-08)

### Исправления (критический баг настройки)

- **Мастер настройки больше не блокируется**, если сервер здания временно
  недоступен. Раньше после ввода ключа кнопка «Подтвердить» крутилась долго
  (30+ секунд), а затем выходила ошибка «no devices». Теперь:
  - если сервер ответил — мастер показывает выбор типов и устройств, как раньше;
  - если сервер не ответил — мастер позволяет **завершить настройку сразу**
    (устройства появятся позже, когда сервер станет доступен);
  - общее время опроса на этапе настройки ограничено ~15 секундами.

### Технические изменения

- `protocol.py`: параметр `timeout` в `get_list()` теперь реально ограничивает
  общее время ожидания (раньше игнорировался, из-за чего опрос зависал).
- `protocol.py`: укорочен таймаут подписки и регистрации (5с → 2с) — при
  недоступном сервере мастер не ждёт эти 5 секунд на каждый банк.
- `config_flow.py`: `_load_devices_sync` ограничен по времени, камеры — первый
  индикатор доступности; если камеры не получены, остальные банки не опрашиваются.
- Файлы интеграции опубликованы без BOM-маркера — корректная загрузка в HA.

## v1.5.4 (2026-10-08)

### Исправления
- Убран шаг `check_server`, который вызывал бесконечное ожидание при нажатии
  кнопки «Подтвердить». Теперь проверка соединения выполняется сразу после
  распознавания ключа, а ошибка показывается понятным русским текстом прямо
  в окне настройки.

### Изменения для пользователя
- При добавлении интеграции вы сразу видите результат подключения к серверу
  здания: если сервер недоступен или не отдаёт устройства, это отдельно
  поясняется — больше нет пустого «no devices».

## v1.5.0 (2026-10-08)

### Новое
- Пошаговый мастер настройки: ввод ключа → выбор типов устройств → выбор
  конкретных устройств → доп. настройки (создать дашборд, добавить в
  «Энергию», тарифы).
- Русский интерфейс мастера, иконки и группировка устройств по типам.
- Ускоренная загрузка: камеры грузятся за ~9 секунд вместо ~30 (пакетный сбор).
- Подготовлены тарифы Архангельска (электроэнергия день/ночь) с настройкой
  по умолчанию и полями под конкретные тарифы воды.
