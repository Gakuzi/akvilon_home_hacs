# Akvilon InHome — Home Assistant integration

Интеграция Аквилон InHome для Home Assistant (Raspberry Pi, хост `klim`).
UDP-протокол к серверу здания `127.0.0.1:19090`.

## Ветки
- `main` — стабильная рабочая версия (первый коммит `0fdd8f7`)
- `develop` — разработка
- `feature/video-stream` — задача: запустить RTP-видео камер
- `feature/video-viewer` — задача: видеокадры всех камер + веб-панель просмотра

## Структура
- `protocol.py` — UDP-клиент (подписка, регистрация, GET-списки, open_gate, openCamera/closeCamera)
- `coordinator.py` — `AkvilonHub`: загрузка камер/калиток/счётчиков/домофонов, `camera_frame` (захват кадра)
- `rtp_stream.py` — приём RTP/H.264 и декод в JPEG (ffmpeg)
- `camera.py` — платформа камер (реальный кадр через executor)
- `viewer.py` — веб-панель просмотра всех камер (сетка, снимки по запросу, MJPEG для выбранной)
- `button.py` — кнопки открытия калиток
- `sensor.py` — счётчики и состояние калиток
- `binary_sensor.py` — онлайн-статус сервера
- `config_flow.py` — мастер настройки

## Видео-механизм камер (2026-10-08, подтверждён)
1. Подключение + MD5-подпись PASS (регистрация НЕ нужна — она ломает сессию).
2. `openCamera` на канал 0x30401 = `{"id":"<flag:oid>","name":"openCamera"}`.
3. Ответ `cameraSettings` на канале 0x2030401: `videoHost/videoPort/videoToken/spropParameter`.
4. Запуск RTP: на `videoHost:videoPort` отправить UDP-датаграмму `b"\x00\x00"+videoToken`.
5. Сервер льёт RTP/H.264 на этот порт; собираем IDR-кадр (FU-A/STAP-A/NAL), декодируем
   через ffmpeg в JPEG. Кадр кэшируется; камера закрывается после захвата (не копить лимит).

## Веб-панель камер (feature/video-viewer)
Запуск: сервис `akv_home.start_viewer` (по умолчанию порт 8090).
- `http://<IP>:8090/` — сетка всех камер с подписями от сервера, группировка по разделам,
  избранное (⭐), фильтр по разделу; клик = живое большое окно (MJPEG).
- `http://<IP>:8090/snap/<camId>` — одиночный кадр JPEG (по запросу, кэш).
- `http://<IP>:8090/mjpeg/<camId>` — живой поток для выбранной камеры (VLC/браузер).
- Обновляются только видимые тайлы (IntersectionObserver, интервал 12–15 с), живой поток
  включается только для выбранной камеры — минимальная нагрузка на Raspberry Pi.
